# OrbitMC — ТЗ

## Цель
Портативный лаунчер Minecraft на Python с входом по нику (offline), выбором любых официальных версий,
установкой Forge / Fabric / Quilt и запуском игры. Всё лежит в одной папке рядом с exe.

## Стек
- Python 3.12, customtkinter 6, Pillow
- minecraft-launcher-lib 8 (official Mojang manifest, mod_loader API, JVM runtime)
- PyInstaller (one-file exe, иконка, фон внутри)
- Inno Setup 7 (установщик с выбором папки)

## Архитектура (portable)
```
OrbitMC/            <- папка приложения
  OrbitMC.exe
  orbitmc.json      <- настройки (ник, RAM, выбранная версия)
  minecraft/        <- игровые данные (versions, libraries, assets, runtime)
  cache/            <- кэш списка версий Mojang (оффлайн-старт)
```
Путь к данным = папка exe, а не %APPDATA%. Ничего вне папки не пишется.

## Функции
1. Вход по нику: 3–16 символов [A-Za-z0-9_], offline UUIDv3 (OfflinePlayer:<ник>).
2. Список всех официальных версий (релизы + снапшоты по галочке), поиск, пагинация.
3. Загрузка версии из официального манифеста Mojang, автоскачивание Java-рантайма Mojang.
4. Модификации: Vanilla / Fabric / Quilt / Forge — установка через mod_loader API.
5. Запуск игры (RAM-слайдер), статус, прогресс, лог.
6. Иконка и фон внутри exe, кнопка «Открыть папку игры».

## Критерии приёмки
- exe запускается, показывает фон и иконку, грузит версии с Mojang.
- Установка и запуск ванильной версии без установленной Java на машине.
- Fabric/Quilt/Forge ставятся для поддерживаемой версии и запускаются.
- Установщик Inno Setup ставит приложение в выбранную папку, ярлыки, деинсталлятор.
- Все данные после установки лежат внутри папки установки.
